# Reference Papers

This document categorizes key papers relevant to CAPTAIN/CELA.

## Foundational Causal Inference
- Pearl, J. (2009). *Causality*. Cambridge university press.
- Peters, J., Janzing, D., & Schölkopf, B. (2017). *Elements of causal inference: foundations and learning algorithms*. The MIT Press.

## Provenance
- Cheney, J., Chiticariu, L., & Tan, W. C. (2009). Provenance in databases: Why, how, and where. *Foundations and Trends in Databases*.

## Agent Tracing and Failure Attribution
- **Who&When Pro**: Large-scale benchmarking of agent trajectories.
- **CAR (Causal Agent Replay)**: Step-level interventional replay using Monte-Carlo Shapley.
- **CausalFlow**: Causal responsibility scores via step-level counterfactuals.
- **AgentRx**: Trajectory IR for finding unrecoverable failure steps.
- **From Spark to Fire**: Modeling error cascades in multi-agent environments.
- **AgenticRAG-FP**: Failure propagation and signal loss in RAG.

## Evaluation & Benchmarking
- **AgentProcessBench**: Fine-grained process-level step evaluation.
- **RAFFLES**: Reasoning-based attribution via LLM-as-judge probing.
